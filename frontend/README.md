# Ledgerly — Frontend

The modern, responsive user interface for **Ledgerly**, built with Next.js and Tailwind CSS. It provides seamless user authentication, dashboard views, account management, and transaction history tracking.

---

## 🚀 Tech Stack

* **Framework:** Next.js (React 19)
* **Styling:** Tailwind CSS
* **Language:** TypeScript
