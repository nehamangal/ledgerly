# Ledgerly — Frontend

The modern, responsive user interface for **Ledgerly**, built with Next.js and Tailwind CSS. It provides seamless user authentication, dashboard views, account management, and transaction history tracking.

---

## 🚀 Tech Stack

* **Framework:** Next.js (React 19)
* **Styling:** Tailwind CSS
* **Language:** TypeScript

---

## ⚙️ Getting Started & Setup

### 1. Navigate to the Frontend Directory
```bash
cd frontend

### 2. Install Dependencies
```bash
npm install

### 3. Configure Environment Variables
      NEXT_PUBLIC_API_URL=http://localhost:8080

### 4. Run the Development Server
      npm run dev
